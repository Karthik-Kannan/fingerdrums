# Fingerdrums

A Melodics-style practice site for finger drumming on grid controllers.

**Milestone 1 – pad grid:** `index.html` is a 16-pad kit you can play from a Novation Launchpad or Launchkey over Web MIDI, the computer keyboard, or by tapping. Sounds are synthesized with Web Audio. Launchpad X / Mini MK3 / Pro MK3 pads light up in Programmer mode.

Web MIDI needs Chrome or Edge (desktop or Android) and an https or localhost page. iOS browsers don't support it.

Run locally: `python3 -m http.server 8000`, then open http://localhost:8000.
